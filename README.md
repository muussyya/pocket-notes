# ポケット基礎ノート

Excel＋タイピング習得ツールの、スマホ用の予習帳（PWA）です。課題の解説、タイピングの基本、ショートカットの暗記カード、基礎の4択クイズが入っています。
ビルド不要の静的ファイルだけで動きます。読んだ記録などは、端末のブラウザ内（localStorage）にだけ保存されます。

このフォルダの中身は、元のツールの `tools/build_mobile.py` が自動で作ります。ここで直接編集しないでください。

## スマホで使うまで

GitHub Pages で公開した URL をスマホで開き、
- iPhone（Safari）：共有ボタン →「ホーム画面に追加」
- Android（Chrome）：メニュー →「ホーム画面に追加」／「アプリをインストール」

一度開けば、オフラインでも使えます。データは「その端末・そのURL」に結びつきます。
